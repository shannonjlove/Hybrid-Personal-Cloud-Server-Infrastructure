# SECURITY RULES — PERMANENT

This repository is for system architecture, automation logic, and documentation only.

NO private files should ever be uploaded here.

NEVER UPLOAD:
• Personal documents
• Legal files or contracts
• Film footage or media
• Photos or private images
• Financial records
• Client materials
• Backups or archives
• Passwords or keys
• API credentials
• Cloud storage credentials
• Server IP addresses
• Database exports

ALLOWED IN THIS REPOSITORY:
• System architecture documents
• Automation scripts (sanitized)
• Placeholder configuration files
• Example folder structures
• Diagrams and documentation

PRIVATE FILE STORAGE LOCATIONS:
All real files must remain inside secured private storage:
• Private cloud servers
• Encrypted storage
• Local secure drives
• Protected backup systems

This repository functions as a blueprint only, not a storage vault.
