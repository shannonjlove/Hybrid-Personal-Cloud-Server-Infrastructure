# Tailscale

Secure mesh VPN connecting all infrastructure nodes.

## Configuration

- **Version**: 1.94.1
- **SSH**: Enabled (--ssh flag)
- **Install Date**: February 7, 2026
- **Tailnet Devices**: sOs, gclove-server-vm-instance, ip-172-31-38-121, shajes-iphone, shannonjlove

## Benefits

- Direct SSH by hostname — no keys or port forwarding needed
- Encrypted mesh VPN between Mac, iPhone, Nexus VPS, and Oracle
- Access Docker container web UIs without exposing ports publicly
- Mobile server management via Tailscale app on iPhone
- Option to close port 22 in OCI Security List for hardened security
