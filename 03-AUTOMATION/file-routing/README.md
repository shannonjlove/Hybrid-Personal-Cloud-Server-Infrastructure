# File Routing

Automated file routing based on PARA categories, naming conventions, and metadata.

## Role

- Ingest pipeline: new files routed to correct PARA category
- Naming convention enforcement: YYYY-MM-DD_HH-MM_category-subcategory_description_UUID24.ext
- 8 shell scripts for routing logic
- LaunchAgents for scheduled execution
