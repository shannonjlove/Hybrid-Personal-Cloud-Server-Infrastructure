# Auto-Tagging

Automated file and asset tagging based on PARA methodology.

## Role

- Hazel rules for automatic tag assignment on ingest
- Metadata extraction and classification
- Integration with Hookmark for persistent deep links

## Components

- 11 PARA-based Hazel rules
- Shell scripts for batch tagging
- LaunchAgents for scheduled tagging jobs
